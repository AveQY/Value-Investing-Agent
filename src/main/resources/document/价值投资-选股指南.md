# 周行五步法
```
周行五步法
1.判断资金属性
先确认用来投资的是闲钱，这是做长线的前提。
2.一句话抓住公司主要矛盾
把银行定位成稳健、高股息的公司，核心判断标准就是：只要高股息还在，银行就不算贵。
3.每日跟踪关键指标
- 跟踪10年期国债收益率（无风险收益率）
- 跟踪保险公司（如平安）对银行股的增持动作，7月后增持明显放缓，信号转弱。
4.判断估值贵还是便宜
以四大行为主，设定标准：
股息率要比无风险收益率高2个百分点才算便宜。
当时无风险收益率约1.7%，对应股息率低于3.7%–3.8%就偏贵。
7月后四大行股息率跌破3.9%、3.8%，判定银行股已经偏贵。
5.结合市场情绪做决策
在估值偏贵+情绪狂热的情况下，选择逆势卖出。
 
这套方法同样适用于买入：闲钱→抓主要矛盾→每日跟踪→判断估值→等待情绪低迷时再考虑回补，坚持每日打卡跟踪，就能更理性判断买卖点，不盲目跟风。

用这套方法评估
```

# 事件驱动类

## 热点追踪
```
解读[事件类型，如数字货币概念]的事件驱动机会，分析龙头股融资余额变化及历史类似事件后的股价表现。
示例：解读数字货币概念的事件驱动机会。
```

## 业绩预告/财报解读(业绩趋势上升)
```
解读[公司名称]最新财报中的[关键指标，如‘毛利率下滑’/‘研发费用激增’]，对比行业均值，分析是否反映竞争力变化，并预测未来3个季度的业绩趋势。
示例：解读宁德时代2023年Q3财报中“存货周转率下降”的影响。
```

## 并购重组机会
```
筛选[行业]中过去6个月发生重大资产重组且公告后股价涨幅低于[X]%的公司，分析重组标的协同效应，并给出潜在催化时间点。
示例：筛选医药行业中重组后涨幅低于20%的公司。
```

## 政策/行业事件影响
```
分析[政策名称/事件类型，如‘AI芯片出口管制’]对[行业A]和[行业B]的短期冲击（1个月内）与长期影响（1年以上），对比龙头公司（如[公司A]、[公司B]）的订单变化、研发投入调整及股价弹性。
示例：分析“光伏组件出口退税取消”对隆基绿能和晶科能源的影响。
```

## 事件驱动概率评估
```
评估[事件类型，如‘年报披露’]对[股票代码]股价的影响概率（高/中/低），并给出事件兑现前后的操作建议。
示例：评估宁德时代年报披露对股价的影响概率。
```

```

## 行业黑天鹅预警
```

## 流动性风险监测
